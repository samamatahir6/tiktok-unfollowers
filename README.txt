TikTok Slow Unfollower v1.2

INSTALL / UPDATE
1. Unzip this folder.
2. In Chrome open chrome://extensions and turn on "Developer mode".
3. If the old version is installed, click "Remove" on it first.
4. Click "Load unpacked" and pick the tiktok-unfollower folder.
5. Refresh any open TikTok tab.

USE
1. Log in to tiktok.com (any page).
2. Click the extension icon and press Start.
   It goes to your profile, opens the Following list and starts unfollowing by itself.
   When the list runs out it refreshes the page and continues until Following is 0.
3. Watch the Log box in the popup. Press Stop any time; progress is saved.

LOGS
- Popup: the Log box shows everything, errors in red.
- Page console: press F12 on the TikTok tab, open Console, type "TikTok Unfollower" in the filter.
- If something fails, press Diagnose and send the log lines.

SAFE DEFAULTS
4 to 9 seconds between unfollows, rest 2 minutes every 25, max 150 per day.
If TikTok shows "too fast" or unfollows stop working, it stops by itself.
